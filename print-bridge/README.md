# CODE QR PRO — Windows Print Bridge

Локальный мост между веб-приложением и термопринтерами Windows (TSC, Zebra, Xprinter, Godex и любые другие с установленным драйвером).

## Запуск
1. Установлен Node.js 20+ (node -v).
2. Двойной клик по start.bat (или node bridge.mjs).
3. В консоли появится токен — скопируйте его в веб-приложении: Кабинет → Этикетки → панель Print Bridge.
4. Держите окно открытым во время печати. Можно добавить ярлык start.bat в автозагрузку (shell:startup).

## Как это работает
- Bridge слушает только 127.0.0.1:9101 (из сети недоступен).
- Веб-приложение рендерит штрихкоды на сервере, отправляет макет этикетки в Bridge.
- Bridge рисует этикетку в точный размер (мм × DPI) через GDI+ и печатает через драйвер Windows с нулевыми полями.
- Токен (bridge-token.txt) защищает от печати посторонними сайтами; CORS разрешён только для code-qr.stockcity.ru.

## Требования к принтеру
- Драйвер установлен, принтер виден в «Принтеры и сканеры».
- В драйвере задан размер этикетки, совпадающий с шаблоном (или используйте пользовательский размер).
- Калибровка зазоров выполнена средствами принтера.

## Безопасность
- Не публикуйте порт 9101 в интернет.
- Токен хранится локально в bridge-token.txt; удалите файл для сброса токена.
