# Категории и данные повторной печати

Дата: 23.11.2026.

## Принцип

Категория задаёт рекомендуемые поля и их приоритет, а не юридический шаблон «один на всех». Этикетка должна содержать читаемый DataMatrix и полезную идентификацию товара. Поля можно менять вручную, если данных карточки недостаточно.

Данные каждой строки подставляются из её карточки по GTIN. Общие поля в «Данных товара» служат запасным шаблоном только там, где карточка не найдена. Правая колонка и `kindQty`/`expiryLine` формируются по данным конкретной строки.

## Важно

- Сроки, состав и обязательные маркировочные поля зависят от товара и правил категории. Сервис не является официальным сервисом ЧЗ и не заменяет проверку требований.
- Не копируйте первый товар на весь пакет: для каждого GTIN используется его карточка.
- Размер 58×40 ограничивает количество текста. Сначала печатаются название, вид/объём и срок, остальные поля — по месту и данным.
- Неофициальные требования к содержимому этикетки могут меняться; проверяйте карточку площадки/ЧЗ перед массовой печатью.
