# Telegram-админ-бот CODE QR PRO

Дата: 21.11.2026. Бот: `@CODE_QR_PRO_bot`.

## Уведомления (приходят автоматически)

- 🆕 новая регистрация клиента;
- 🧾 **выставлен счёт юрлицу** — реквизиты покупателя, сумма, номер, статус «ожидает оплаты», **PDF счёта прикреплён**;
- ✅ **счёт оплачен / оплата получена** — тариф, срок, сумма, номер заказа/счёта, статус `оплачен`;
- ❌ заказ отменён;
- 🆘 новое обращение в поддержку (с кнопками «В работу» / «Закрыть»);
- 🔄 изменение статуса клиента (блокировка, компенсация, продление и т.п.).

У каждого сообщения о заказе есть inline-кнопки: подтвердить оплату, открыть PDF счёта, посмотреть заказ, перейти в админку.

## Команды

| Команда | Что делает |
|---|---|
| `/start`, `/menu`, `/help` | меню и справка |
| `/stats` | пользователи, подписки, выручка, ожидающие оплаты, счета, обращения, ошибки |
| `/orders` | заказы в статусе «ожидает оплаты» с кнопками |
| `/invoices` | неоплаченные счета юрлиц |
| `/order <id>` | карточка заказа |
| `/invoice <id>` | отправить PDF счёта в чат |
| `/users` | последние клиенты с карточками |
| `/user <email или id>` | найти клиента, заблокировать/разблокировать |
| `/tickets` | открытые обращения, «В работу» / «Закрыть» |
| `/jobs` | статусы заданий и последние ошибки |
| `/id` | chat_id (для настройки доступа) |

Кнопки в меню дублируют основные команды. Доступ есть только у chat_id из `TELEGRAM_ADMIN_ID`; остальным бот отвечает «Доступ только для администратора».

## Настройка

В `.env` сервера:

```
TELEGRAM_BOT_TOKEN=...
TELEGRAM_ADMIN_ID=5225857181
```

Несколько администраторов — через запятую. Бот работает через long polling; webhook не нужен (при старте вызывается `deleteWebhook`).

В **админке → Настройки → Telegram-админ-бот** видно статус, chat_id админов и кнопка **«Отправить тестовое сообщение»**.

Важно: с сервера Node `fetch` до `api.telegram.org` таймаутится, поэтому бот и уведомления ходят через системный `curl` (`server/src/lib/telegram-api.js`). На уведомления добавлен повтор при временной сетевой ошибке.

## Безопасность

- сообщения и кнопки обрабатываются только для chat_id из `TELEGRAM_ADMIN_ID`;
- подтверждение оплаты в боте запрашивает отдельное подтверждение (кнопка «Да, подтвердить»);
- отмена через бота разрешена только для неоплаченных банковских счетов; карточные платежи отменяются в админке через ЮKassa;
- блокировка администраторов запрещена;
- действия бота пишутся в журнал (`app_log`, source `telegram`).
