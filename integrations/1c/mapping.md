# Сопоставление документов 1С и API

| 1С | CODE QR PRO |
|---|---|
| Номер документа | name |
| Полный код маркировки (DataMatrix, с криптохвостом) | rows[].data |
| Формат печати | format: png/svg |
| Режим данных | mode: cz |
| Уникальный идентификатор документа | idemKey |

## Важно

- передавать полный код, а не только GTIN/серийник;
- не отправлять пустые строки;
- одна отправка — один документ/пакет;
- idemKey защищает от повторной отправки при сбое;
- код маркировки заказывается и вводится в оборот в 1С/ЧЗ; сервис печатает этикетки и проверяет коды.
