# Аудит повторной печати этикеток

Дата: 23.11.2026.

## Найдено и исправлено

- **Двойное списание операций:** если лимит операций уже израсходован, а экспорт запрещён, операции за несостоявшуюся сборку PDF теперь откатываются.
- **Ошибка сборки:** синхронная сборка PDF и фоновая задача возвращают операции и экспорт при ошибке, включая нехватку памяти для PDF-тикета.
- **Идемпотентность:** клиент повторной печати передаёт стабильный `idemKey` для неизменного пакета. Повторное создание task возвращает существующую задачу (`duplicated: true`), а не новую платную сборку.
- **Удалённые задания:** `deleted_at IS NULL` теперь проверяется и при PDF, и при подготовке печати. Из корзины повторно напечатать нельзя.
- **Доступ сотрудников:** PDF-задачи и PDF-ссылки привязаны к `userId + memberId`. Один сотрудник не видит задачи/файлы другого сотрудника общего аккаунта.
- **Двойной клик:** клиент игнорирует повторное нажатие во время выполнения.
- **Instagram WebView:** ошибки встроенного Android/Instagram `iabjs://navigation_performance_logger_android` и `Java object is gone` не отправляются в журнал клиента как ошибки приложения.

## Проверка

- регрессионный тест отката: операции 3 + экспорт 1 списаны, затем восстановлены; повторный откат — no-op;
- `node --check` для `usage.js`, `routes-labels.js`, `pdf-tickets.js`;
- production: `POST /api/labels/pdf` вернул 200, `application/pdf`, сигнатура `%PDF`;
- production: повторный `POST /api/labels/pdf/task` вернул `duplicated: true`;
- production: health `ok`, сайт `200`, сервис активен;
- временный QA-пользователь и его записи удалены.

## Оставшиеся рекомендации

- Ограничивать повторную печать по составу пакета, а не только ключом: текущий idemKey не сверяет содержимое запроса при повторе.
- Для полного атомарного пакета списаний использовать транзакцию вокруг `consumeOperations + consumeExports` с явным rollback (текущий откат покрывает ошибки сборки и лимит экспорта).
- Добавить E2E-проверку UI повторной печати на iOS/Android и проверку отказа доступа между двумя сотрудниками.
