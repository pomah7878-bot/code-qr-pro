# SEO и аналитика в админке CODE QR PRO

Дата: 21.11.2026. Раздел `/app/admin/analytics` («Маркетинг → SEO и аналитика»).

Изучены официальные материалы:
- [О сервисе Яндекс Вебмастер](https://yandex.ru/support/webmaster/ru/service/info) — какие данные даёт сервис: поисковые запросы и позиции, диагностика, индексирование, Sitemap, ссылки, уведомления, API.
- [Обзор ресурсов API Вебмастера](https://www.yandex.com/dev/webmaster/doc/ru/concepts/getting-started) — `/summary`, `/diagnostics`, `/sitemaps`, `/search-queries/popular`, `/indexing/history` и другие ресурсы.

## Что видно в дашборде

- **KPI:** визиты, посетители, просмотры, поисковый трафик и его доля, краулинг ботов, регистрации, активации триала, оплаты и выручка, конверсия визит → регистрация, средняя позиция и CTR по Яндексу.
- **Динамика трафика** за 7/30/90 дней: визиты, просмотры, поисковый трафик, краулинг ботов; сравнение последней недели с предыдущей.
- **Источники трафика:** прямые заходы, Яндекс/Google/Bing/Mail.ru/DuckDuckGo/Дзен, соцсети, email, другие сайты, UTM-кампании.
- **Поисковые системы и устройства:** распределение органики по поисковикам, компьютеры/телефоны/планшеты.
- **Топ страниц и посадочных страниц**, топ поисковых запросов.
- **Индексация:** заходы поисковых роботов (Яндекс, Google, Bing, Mail.ru и др.), какие страницы обходят, последний заход.
- **Здоровье SEO:** оценка 0–100 и чек-лист (HTTPS, sitemap, robots.txt, canonical/meta, контент, юр. документы, JSON-LD FAQ, мобильная адаптация).
- **Яндекс.Вебмастер:** подключение OAuth-токена, автоопределение хоста, синхронизация запросов (показы, клики, CTR, позиции).
- Экспорт дневной статистики в CSV, автообновление раз в 60 секунд.

## Источники данных

| Источник | Что даёт | Как включается |
|---|---|---|
| Собственный трекер | просмотры публичных страниц, источники, referrer, UTM, устройства, сессии/посетители | автоматически, код в `web/src/lib/analytics.js`, маяк `POST /api/analytics/collect` |
| Серверный хук | заходы поисковых ботов по User-Agent | автоматически, `onResponse` в `server/src/index.js` |
| Импорт access-логов | история визитов и ботов за прошлые дни | `node scripts/analytics-import-nginx.mjs --days=30` из `/opt/code-qr/server` |
| Яндекс.Вебмастер | показы, клики, CTR, позиции, реальные поисковые фразы | OAuth-токен в блоке «Яндекс.Вебмастер» |
| Конверсии | регистрации, триалы, оплаты | пишутся сервером при событиях |

IP-адреса для веб-аналитики не сохраняются. Трекер уважает `Do Not Track`; сторонних счётчиков и рекламных пикселей нет.

## Подключение Яндекс.Вебмастера

1. Создайте приложение на `oauth.yandex.ru` (платформа «Веб-сервисы»):
   - **Доступ к данным:** `webmaster:hostinfo` — «Яндекс.Вебмастер API». Не нужны `webmaster:verify` (добавление сайтов/индексирование) и `direct:api`.
   - **Redirect URI:** `https://code-qr.stockcity.ru/app/admin/analytics`.
2. Скопируйте **Client ID** приложения.
3. В админке «SEO и аналитика» → блок «Яндекс.Вебмастер»: вставьте Client ID → «Сохранить Client ID».
4. Нажмите «Получить токен в Яндексе» → войдите аккаунтом, у которого в Вебмастере подтверждён хост `code-qr.stockcity.ru`.
5. После редиректа страница автоматически примет `access_token` и сохранит его на сервере (в зашифрованном виде).
6. Нажмите «Синхронизировать запросы» — данные появятся в блоке «Поисковые запросы» (показы/клики/CTR/позиции). Хост определяется автоматически; при необходимости можно указать `host_id` вручную.
7. Если хост ещё не добавлен в Вебмастер — сначала добавьте и подтвердите его в панели Вебмастера.

Токен хранится в `app_settings` в зашифрованном виде (`webmaster_token` в списке секретов). Если токен невалиден, админка покажет ошибку и не сохранит его.

### Что ещё берём из API Вебмастера

Помимо поисковых запросов синхронизируются:

- **Статистика сайта** (`/summary`): ИКС, количество страниц в поиске и исключённых, проблемы по категориям FATAL/CRITICAL/POSSIBLE_PROBLEM/RECOMMENDATION.
- **Диагностика** (`/diagnostics`): активные проблемы сайта с серьёзностью и датой изменения.
- **Sitemap** (`/sitemaps`): количество файлов, URL, ошибки, дата последнего обхода.
- **Поисковые запросы** (`/search-queries/popular`): показы, клики, CTR, средняя позиция.

Эти данные влияют на SEO-чек-лист: при подключённом Вебмастере добавляются проверки «Страницы в поиске Яндекса», «Диагностика Вебмастера» и «Sitemap в Вебмастере».

## Импорт истории из nginx

На сервере (root нужен для чтения логов):

```bash
cp scripts/analytics-import-nginx.mjs /opt/code-qr/server/scripts/
cd /opt/code-qr/server
node scripts/analytics-import-nginx.mjs --days=30
chown -R codeqr:codeqr data
```

Скрипт идемпотентен: перед импортом удаляет прошлые строки `origin='import'` за период и заново разбирает access-логи (включая `.gz`). Сегодняшний день не импортируется, чтобы не задваивать живой трекер. Импортируются только публичные страницы; `/api`, `/app` и ассеты пропускаются.

Результат первого импорта на проде: 662 просмотра публичных страниц и 36 заходов ботов за 14 дней (по логам с 07.11.2026).

## Ограничения

- Показы/позиции и реальные поисковые фразы доступны только после подключения Яндекс.Вебмастера: поисковики часто скрывают запрос в referrer.
- Google Search Console пока не подключён; при необходимости добавляется аналогичным блоком (OAuth/service account).
- Данные по ботам зависят от того, что реально доходит до сервера; JS-трекер ботов не учитывает.
- Оценка SEO — технический чек-лист, а не гарантия позиций.
