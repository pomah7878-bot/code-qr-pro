# Онлайн-проверка кодов «Честного ЗНАКа»

Дата: 21.11.2026.

## Что теперь работает

`POST /api/cz/verify` после локальной проверки GS1 запрашивает онлайн-статус кодов:

- **без токена** — публичный мобильный API `https://mobile.api.crpt.ru/mobile/check` (тот же источник, что уже используется для карточек товара);
- **с токеном** — официальный True API `POST https://markirovka.crpt.ru/api/v3/true-api/cises/info` с `Authorization: Bearer`.

По умолчанию онлайн проверяются первые **20** валидных кодов (лимит публичного API, настраивается параметром `onlineLimit`, максимум 50). Остальные коды проверяются локально. Для массовой проверки до 1000 кодов за запрос нужен True API.

В результаты добавляются `online`, `onlineSource`, `status`, `statusRaw`, `crypto`, `found`, `warnings`. На странице `/app/cz` появляется бейдж «Онлайн ЧЗ», статус и криптозащита в таблице, а подсказка объясняет источник проверки.

Токен True API можно указать в **Админка → Настройки → Честный ЗНАК**: включить интеграцию, указать `cz_api_url` и вставить токен. При наличии токена проверка сначала идёт через True API, а публичный API дополняет криптоподпись и карточку; если токен истёк — автоматически используется публичная проверка.

## Официальный True API: что нужно

По открытым клиентам и документации ЦРПТ:

1. Быть зарегистрированным участником оборота в ЛК ГИС МТ (`markirovka.crpt.ru`).
2. Иметь действующий сертификат **УКЭП** (КриптоПро CSP / CAdES-BES).
3. Получить токен по схеме:
   - `GET /api/v3/true-api/auth/key` → `{ uuid, data }`;
   - подписать `data` сертификатом (CAdES-BES);
   - `POST /api/v3/true-api/auth/simpleSignIn` `{ uuid, data, unitedToken: true, inn }` → `{ token }`.
4. Токен живёт **около 10 часов**, «вечного» токена нет — нужна повторная авторизация.

Поэтому «просто включить True API» без сертификата и регистрации нельзя. Для самозанятого без статуса участника оборота официальный True API недоступен; публичная проверка статуса работает.

## Источники

- [theYahia/chestnyznak-mcp](https://github.com/theYahia/chestnyznak-mcp) — открытый MCP-клиент: публичный `/mobile/check` без токена, True API по токену, авторизация через УКЭП, токен ~10 часов.
- [akdengi/sklad-cz — docs/15-api-chestny-znak.md](https://github.com/akdengi/sklad-cz/blob/master/docs/15-api-chestny-znak.md) — базовый URL True API, `/auth/key`, `/auth/simpleSignIn`, `/cises/info` (до 1000 кодов), статусы `INTRODUCED` и др.
- [chestny-znak-mcp-ru на PyPI](https://pypi.org/project/chestny-znak-mcp-ru/) — описание challenge-response через КриптоПро и срок жизни токена.
- [Личный кабинет ГИС МТ](https://markirovka.crpt.ru) — регистрация участника и выпуск токена API.

## Ограничения публичного API

`mobile.api.crpt.ru/mobile/check` — **недокументированный endpoint мобильного приложения**, не официальный контракт True API. Он может меняться, имеет рейт-лимиты и не гарантирует SLA. Для продукта с юридически значимой проверкой нужен True API по договору/токену участника.

## Что можно сделать дальше

- если появится УКЭП и регистрация участника — можно добавить автоматическое получение токена через CryptoPro/внешний сервис подписи (сейчас токен вставляется вручную и действует ~10 часов);
- для массовых проверок — переключиться на `/cises/info` пакетами до 1000 кодов;
- публичную проверку оставить как бесплатный fallback для розничных пользователей.
