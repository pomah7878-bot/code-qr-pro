# Аудит админ-панели CODE QR PRO (21.11.2026)

## Что было

- Меню из 14 плоских пунктов без логики: `Обзор · Клиенты · Платежи · Тарифы и подписки · Задания · Хранилище · Маркетинг · Реклама · Аудит · Ошибки · Поддержка · AI-помощник · Помощь · Настройки`.
- Пункт **«Помощь»** вёл в клиентский раздел и не относился к админке.
- В админ-лейауте дублировалась **клиентская навигация** (SideNav) — две навигации на странице.
- **«Платежи»** существовали дважды: отдельный раздел с подтверждением/возвратами и вкладка в «Тарифы и подписки» (только чтение).
- **«Настройки»** дублировали управление тарифами: старый блок «Тарифы PREMIUM», карточка лимитов FREE/PREMIUM и отдельная цена тестового тарифа — расходились с новым разделом «Тарифы и подписки».
- В карточке клиента были старые кнопки «Выдать/Снять PREMIUM», дублирующие назначение тарифа, продление и триал.
- В фильтре клиентов фигурировал только `PREMIUM`, хотя тарифов четыре.
- Аналитика MRR считала `plan='premium'` (после перехода на PRO/START/BUSINESS показатель стал нулевым), в карточке клиента — старая метка «PREMIUM до».
- Роль **support** технически не видела админку: лейаут показывал «доступно только администратору», хотя API и маршруты для поддержки уже были.
- Устаревшие API `/api/admin/plans`, `/api/admin/pricing`, `/api/admin/billing/payments` больше не используются.
- Неиспользуемый компонент `PlanLimitsCard.vue`.

## Что сделано

1. **Меню сгруппировано по смыслу:**

| Группа | Пункты |
|---|---|
| Обзор | Сводка |
| Клиенты и деньги | Клиенты · Платежи · Тарифы и подписки |
| Сервис | Задания · Хранилище · Ошибки · Аудит |
| Поддержка и AI | Обращения · AI-помощник |
| Маркетинг | Рассылки и акции · Реклама |
| Система | Настройки |

2. Удалён пункт «Помощь», убрана дублирующая клиентская навигация из админки.
3. Удалена вкладка «Платежи» из «Тарифов и подписок» — остался полноценный раздел «Платежи» (подтверждение, отмена, возврат, проверка).
4. Из «Настроек» удалены старые «Тарифы PREMIUM», лимиты FREE/PREMIUM и цена теста; вместо них — ссылка «Открыть «Тарифы и подписки»».
5. Из карточки клиента убраны старые «Выдать/Снять PREMIUM» → карточка «Подписка» со сроком и ссылкой «Управлять тарифом».
6. Фильтр клиентов: FREE / START / PRO / BUSINESS; подписи «PREMIUM до» заменены на «Подписка до».
7. Аналитика: количество платных пользователей считается по `start/pro/business`, MRR — по активным подпискам и ценам из таблицы `plans`.
8. Роль **support** теперь может работать с разрешёнными разделами (Клиенты, Задания) без денежных и системных разделов.
9. Удалены мёртвые API (`/api/admin/plans`, `/api/admin/pricing`, `/api/admin/billing/payments`), клиентские методы и компонент `PlanLimitsCard.vue`.
10. Обновлены пользовательские тексты «PREMIUM» → PRO/START/BUSINESS (Dashboard, Generator, Help, History, Labels, API, SEO, подсказки AI).
