# Telegram-админ-бот CODE QR PRO

Бот: `@CODE_QR_PRO_bot`. Доступ только для chat_id из `TELEGRAM_ADMIN_ID`.

## Что это теперь

Полноценный удалённый админ-центр: сводка, клиенты, платежи, счета, поддержка, задания, система, бэкапы и обслуживание — без открытия браузера.

## Меню

Главное меню:

- 📊 Сводка
- 👥 Клиенты
- 💳 Ждут оплаты
- 🧾 Счета юрлиц
- 🎫 Поддержка
- ⚠️ Задания
- 🖥 Система
- 🌐 Админка

У каждого раздела есть кнопка возврата в меню. Опасные действия требуют подтверждения.

## Команды

| Команда | Действие |
|---|---|
| `/start`, `/menu` | главное меню |
| `/help` | справка |
| `/stats` | сводка: пользователи, подписки, выручка, ожидающие оплаты, обращения, ошибки |
| `/users` | клиенты по страницам |
| `/user <email или id>` | карточка клиента |
| `/find <email/id/номер>` | поиск клиента или заказа |
| `/orders` | заказы, ожидающие оплаты |
| `/invoices` | неоплаченные счета юрлиц |
| `/order <id>` | карточка заказа |
| `/invoice <id>` | отправить PDF счёта в чат |
| `/receipt <order id>` | выпустить чек НПД |
| `/tickets` | обращения поддержки |
| `/jobs` | очередь и ошибки заданий |
| `/system` | сервер, интеграции, бэкап, режим обслуживания |
| `/id` | chat_id |

## Управление клиентом

В карточке клиента доступно:

- заблокировать/разблокировать (сессии завершаются);
- продлить подписку на 30 дней;
- выдать пробный период;
- сменить тариф на PRO / BUSINESS / ENTERPRISE;
- сбросить 2FA (сессии завершаются);
- обнулить счётчики лимитов;
- включить/отключить письма;
- открыть карточку в веб-админке.

## Платежи и чеки

- подтвердить оплату с отдельным подтверждением;
- отменить неоплаченный счёт;
- скачать PDF счёта в чат;
- открыть ссылку онлайн-оплаты ЮKassa;
- открыть/повторно отправить чек НПД;
- выпустить чек НПД для оплаченного заказа.

## Поддержка и задания

- открытые обращения с текстом и клиентом;
- «В работу» / «Закрыть»;
- статусы заданий и последние ошибки.

## Система

- аптайм, RSS, диск, БД и WAL;
- размер очереди и ошибки;
- состояние SMTP, ЮKassa, Telegram, НПД;
- последний бэкап и его возраст;
- включение/выключение режима обслуживания с подтверждением.

## Команды Telegram

При старте бот вызывает `setMyCommands`, поэтому основное меню доступно в кнопке «Меню» рядом с полем ввода.

## Безопасность

- только администраторы из `TELEGRAM_ADMIN_ID`;
- подтверждения для блокировки, продления, сброса 2FA, смены тарифа, обслуживания;
- действия пишутся в `app_logs` (`source=telegram`);
- блокировка администратора запрещена;
- токен и chat_id не выводятся в интерфейс.

## Технически

- long polling через системный `curl`;
- короткий polling без long-poll (timeout=0) для стабильности в РФ;
- `deleteWebhook` при старте;
- `telegram_offset` сохраняется в `app_settings`;
- при конфликте 409 бот удаляет webhook и продолжает.
