# Раздел «Маркетплейсы»

Дата: 25.11.2026. Кабинет: `/app/marketplaces`. Доступ — все клиенты, лимиты по тарифу (учёт операций/экспорта общий с editorом этикеток).

## Что умеет

- **Товарные этикетки** — генерация по версионируемым профилям площадок: данные товара вручную, из сохранённых товаров или автозаполнение из ЧЗ (`/api/cz/product`), предпросмотр с реальными штрихкодами, PDF точного физического размера, лист А4, печать из браузера.
- **Транспортные этикетки** — загрузка оригинала PDF/PNG из кабинета площадки и печать **без перерисовки**: PDF отдаётся байт-в-байт (печать в фактическом размере из просмотрщика), PNG размещается на странице точного размера профиля.
- **Мои товары** — поиск, редактирование, архив, удаление (до 1000 активных).
- **Документы** — список загруженных оригиналов (до 300, до 20 МБ), повторная печать/скачивание, удаление. SHA-256 и сигнатуры PDF/PNG проверяются при загрузке.
- **Тестовая линейка 100 мм** — проверка масштаба принтера.

Профиль без `sourceUrl` + `verifiedAt` помечается `requiresCheck` и не может быть активирован для генерации. Транспортные профили не генерируются — только оригинал из кабинета (стикер WB и этикетки Ozon/ЯМ содержат уникальные коды площадки).

Ключевые требования площадок учтены в подсказках профилей: Code-128 для WB (обязателен при ведущем нуле), совпадение баркода «товар = карточка = поставка», EAN-8/13/14/UPC/Code39 для Ozon (DataMatrix как баркод товара не поддерживается), состав на русском и сроки годности для ЯМ, КИЗ DataMatrix — через «Генерацию»/«Повторную печать».

## Коробки (грузоместа) — разносортная отгрузка

Вкладка «Коробки» закрывает сценарий «производство отгружает коробами с разными товарами на разные площадки»:

1. **Короб** = грузоместо: площадка + схема (FBS/FBO) + название + статус (собирается / готов / отгружен).
2. **Состав**: позиции «товар × количество» из сохранённых товаров или вручную (название + штрихкод); у каждой позиции свой профиль товарной этикетки.
3. **Пошаговая инструкция** под площадку и схему (BOX_GUIDES в server/src/marketplaces.js): что клеить на товар, что на короб, что нельзя. Источники: WB «Отгрузка FBS в ПВЗ» (ред. 09.11.2026), WB «Маркировка товаров и поставок», Ozon Seller Edu (штрихкоды; страница FBO-грузомест заблокирована антиботом — размеры в подсказке помечены «по сторонним источникам»), Яндекс Маркет «Ярлык на заказ» / «Наклеить этикетки».
4. **PDF этикеток товаров** — один файл на все вложения: каждая этикетка страница точного размера своего профиля (renderMixedLabelsPdfBuffer в labels.js). Лимит 1000 единиц на короб.
5. **Упаковочный лист А4** — внутренний документ для сверки (не этикетка площадки): состав, количества, итог.
6. **Этикетка короба** — оригинал из кабинета площадки (QR грузоместа WB, этикетка отправления/грузоместа Ozon, ярлык ЯМ): загрузка PDF/PNG, привязка к коробу, печать без перерисовки.

Ключевые правила, зашитые в подсказки: WB FBS — стикер заказа на каждую единицу ВНУТРИ короба, QR грузоместа (WB-MP) на короб, товарные стикеры на короб НЕ клеить (штрафы/недостачи); 1 короб = 1 грузоместо, ≤80 см сторона, ≤25 кг; Ozon FBS — этикетка отправления на короб + товарный штрихкод на каждый товар, без сторонних маркировок; Ozon FBO — этикетка грузоместа на короб/палету (минимум 120×75, рекомендуется А4 — требует проверки в кабинете); ЯМ — свой ярлык на каждое грузоместо, КГТ ≥4 ярлыков.

### API коробов

- `GET/POST /api/marketplaces/boxes`, `GET/POST/DELETE …/boxes/:id`
- `POST …/boxes/:id/items`, `POST/DELETE …/boxes/:id/items/:itemId`
- `POST …/boxes/:id/labels/pdf` — пакетный PDF (учёт операций по числу единиц, idemKey `:mp_box_pdf`)
- `POST …/boxes/:id/packing-list` — упаковочный лист А4 (1 экспорт, `:mp_box_list`)
- `POST …/boxes/:id/link-document` — привязка/отвязка оригинала этикетки короба

Миграция v57: `marketplace_boxes`, `marketplace_box_items`. Лимиты: 200 коробов, 200 позиций в коробе.

## API

- `GET /api/marketplaces/overview` — площадки, профили, счётчики.
- `GET/POST /api/marketplaces/products`, `POST …/:id/archive`, `DELETE …/:id`.
- `POST /api/marketplaces/labels/preview` — проверка полей + элементы макета с PNG.
- `POST /api/marketplaces/labels/pdf` (+ `/ticket`, `GET …/pdf/file/:id` для iOS) — `{profileId, productId|fields, copies, mode: label|a4, idemKey}`.
- `POST /api/marketplaces/labels/print` — HTML для системного диалога печати.
- `POST /api/marketplaces/documents/upload?marketplace=&kind=&profileId=&filename=` — сырой буфер PDF/PNG (Content-Type), до 20 МБ.
- `GET /api/marketplaces/documents`, `GET …/:id` (`?download=1`), `POST …/:id/print`, `DELETE …/:id`.

Списание операций идемпотентно по `idemKey` (суффиксы `:mp_pdf`, `:mp_pdf_export`, `:mp_print`, `:mp_doc_print`), при ошибке сборки — откат. CSRF: общий `sameOriginGuard` (Origin обязателен).
