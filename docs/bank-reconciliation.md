# Сверка банковской выписки

Раздел: **Админка → Клиенты и деньги → Сверка выписки**.

## Зачем

Онлайн-платежи ЮKassa активируются автоматически по вебхуку и резервной сверке каждые 30 секунд. Обычный банковский перевод ЮKassa не видит, поэтому для B2B-счетов можно загрузить выписку банка: сервер найдёт поступления, сопоставит их со счетами и активирует доступ.

## Форматы

### CSV

Файл с заголовками (разделитель `;`, `,` или табуляция):

- `Дата` / `Дата операции` / `Дата проводки`;
- `Сумма` / `Поступление` / `Сумма в валюте счета`;
- `Плательщик` / `Наименование плательщика`;
- `ИНН` / `ИНН плательщика`;
- `Назначение платежа` / `Назначение`.

Загружаются только положительные входящие суммы. Исходящие и списания пропускаются.

### 1С

Файл `1CClientBankExchange` (выгрузка из 1С/банка) с секциями входящих платёжных поручений. Кириллица в UTF-8 или Windows-1251 определяется автоматически.

### Excel

Прямой `.xlsx` пока не поддерживается: выгрузите CSV или 1С из интернет-банка.

## Правила сопоставления

1. Сумма поступления должна совпадать с суммой счёта (до копейки).
2. Приоритет — номер счёта в назначении платежа (`СЧ-2026-0010`).
3. Если номера нет, но есть ИНН плательщика и ровно один счёт на эту сумму — сопоставление по ИНН.
4. Если подходящих счетов несколько или данных не хватает, строка остаётся в «Несопоставленных»; администратор выбирает счёт вручную.
5. Повторная загрузка того же файла не создаёт дубли: строки идентифицируются по хешу даты, суммы, ИНН, плательщика и назначения.

## Что происходит после сопоставления

- заказ переводится в `paid`;
- активируется тариф/архив;
- начисляется конверсия;
- выполняется попытка выпуска чека НПД (если интеграция с «Мой налог» настроена);
- строка выписки сохраняется со ссылкой на заказ и временем сопоставления.

## Ограничения

- Выписка загружается вручную; автоматическая загрузка из банка требует API/выгрузки на стороне банка.
- Если платёж пришёл неполной суммой, автоматическое сопоставление не выполняется.
- Для юрлица в чеке НПД нужен ИНН покупателя; он берётся из реквизитов B2B-заказа.
