## Как считаются лимиты

1. **Генерация** — одна операция за один успешно обработанный код в задании/PDF. Ошибки и отклонённые строки не списываются.
2. **Расширенные проверки** — отдельный лимит. Повторная проверка того же кода в пределах TTL (15 минут по умолчанию) берётся из кэша и не списывается; повтор с тем же `idemKey` также не списывается.
3. **Экспорт** — отдельный лимит на скачивание PDF/ZIP и печать наборов. Один запрос экспорта = одна единица.
4. **API** — отдельный лимит на каждый запрос с API-ключом. Генерация через API дополнительно расходует лимит кодов.
5. **Внешние запросы** учитываются в `external_requests` с `cost_units` для контроля себестоимости; ошибки внешних API не списывают лимит.
6. **80% и 100%** — в «Подписке» показываются прогресс-бары и предупреждения по каждому лимиту; на дашборде появляется ссылка на тарифы.
7. **Автоматического повышения тарифа нет.** При исчерпании лимита генерация/проверки/экспорт/API останавливаются до нового периода или ручной смены тарифа.
8. Стоимость самих кодов маркировки «Честный ЗНАК» в подписку не входит.

## Технические точки

- `plans`: `ops_per_period`, `checks_per_period`, `exports_per_period`, `api_calls_per_period`.
- `usage_periods`: `ops_used`, `checks_used`, `exports_used`, `api_calls_used`.
- `usage_events`: журнал списаний с `idem_key` и `external`.
- `external_requests`: стоимость/ошибки/латентность внешних API.
- `usageSummary()` отдаёт прогресс и флаги 80/100 для кабинета.
