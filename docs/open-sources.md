# Проверка забора информации из открытых источников

Дата: 21.11.2026. Проверено на проде `code-qr.stockcity.ru`.

## Источники и порядок

1. **«Честный ЗНАК» — проверка кода** (`mobile.api.crpt.ru/mobile/check`): статус кода, криптоподпись, даты производства/годности, состав, производитель, страна, срок службы, вид товара.
2. **Национальный каталог маркированных товаров** (тот же API по GTIN): наименование, бренд, производитель, категории, атрибуты, изображения.
3. **Open Food Facts / Open Beauty Facts / Open Products Facts** — резервные открытые базы по GTIN, если товара нет в Нацкаталоге или каталог отдал только название/бренд. Используются для состава, объёма, категории и фото.

Короткие коды (без 91/92) не проверяют статус в обороте — это отображается предупреждением. Ошибки источников не списывают проверки. Успешный внешний запрос стоит 1 проверку, повторный GTIN — из кэша без списания.

## Найденные и исправленные баги

| Проблема | Было | Стало |
|---|---|---|
| Даты из ГИС МТ | `1785974400` в таблице | `06.08.2026` (unix ms/sec, ISO, YYMMDD) |
| Статус кода | `INTRODUCED` латиницей | `В обороте` (регистронезависимый маппинг) |
| Криптозащита | могла показываться «Проверено» при `checkResult=false` | честно «Не проверено» + предупреждение о криптоподписи |
| Объём | пусто/`2` | `2 мл` (приоритет данных конкретного кода) |
| Срок службы | пусто | `2 сут; дн` |
| Категория | `gtin` (тип кода) | `Уходовая косметика` (из каталога) |
| Каталог без состава | только название/бренд | дополняется из Open Food Facts |
| Изображение товара | не выводилось | фото из Open Food Facts |

## Результаты проверки

Полный код `(01)04638230913287(21)5ZsWrd(91)EE12(92)…`:

- наименование: сыворотка «LF», бренд LIGHT FIT;
- производитель: ООО «НПЦ МИГ» (полное из каталога);
- категория/вид: Уходовая косметика / СЫВОРОТКА;
- объём: 2 мл; срок службы: 2 сут; дн;
- изготовлен: 06.08.2026; годен до: 06.08.2028;
- статус: В обороте; криптоподпись: Не проверено (у тестового кода невалидный криптохвост — предупреждение выводится);
- состав: 14 компонентов из ГИС МТ.

Короткий код Nutella `(01)03017620422003(21)ABC123`:

- Нацкаталог: полное наименование и бренд; Open Food Facts дополнил категорию, объём `400 g e`, состав и фото;
- статус в обороте не проверяется (короткий код) — выведено предупреждение.

Чистый fallback Open Food Facts (нет в ЧЗ): GTIN `5000159484695` → Twix, категория, объём, состав, источник Open Food Facts.

Ошибочный GTIN `99999999999999` → карточка не найдена, понятное предупреждение, проверки не списаны.
