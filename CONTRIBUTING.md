# Участие в проекте

CODE QR PRO развивается самостоятельно. Репозиторий закрытый, исходный код
является собственностью правообладателя.

## Что приветствуется

- сообщения об ошибках без публикации чувствительных данных;
- идеи по улучшению сервиса;
- предложения по безопасности — только на code-qr-pro@mail.ru;
- финансовая поддержка: https://code-qr.stockcity.ru/support.

## Что не принимается

- pull request с кодом без предварительного письменного соглашения;
- копирование, форк и повторное использование кода;
- публикация уязвимостей и чужих данных;
- массовые рассылки, спам и реклама в Issues.
